# ⚙️ Techtober Challenge

Welcome to the official **Techtober Challenge** repository! 

Это интенсивный 4-недельный технический марафон, созданный для всех, кто хочет прокачать свои инженерные навыки, развить дисциплину и заявить о себе в IT-сообществе.

## 📅 Программа марафона (4 недели)

Каждый этап приближает вас к созданию уникального технологичного устройства — дерева-ночника на солнечной батарее.

| Неделя | Название этапа | Техническое задание |
| :--- | :--- | :--- |
| **Неделя 1** | 🍃 **Leaf (Лист)** | 1. Используя 3D-ручку, создать вокруг квадратного элемента солнечной панели контур листика вашего любимого дерева и аккуратно заштриховать его.<br>2. Припаять два провода к контактам панели: **красный** провод к **«+»**, **чёрный** — к **«-»**. |
| **Неделя 2** | 🪵 **Trunk (Ствол)** | 1. Спроектировать и создать конус в виде ствола дерева (используя 3D-ручку, картон или другие доступные материалы).<br>2. Предусмотреть в стволе специальные технологические отверстия для крепления готовых листьев. |
| **Неделя 3** | 🔋 **Base (База)** | 1. Собрать устойчивое основание (базу) для всей конструкции.<br>2. Разместить внутри базы аккумуляторный отсек и выключатель для управления светом. Скоммутировать силовую часть. |
| **Неделя 4** | 🌸 **Flower (Цветок)** | 1. Создать финальный элемент — соцветие ночника.<br>2. Интегрировать в него светодиод, подключить к общей цепи питания и провести финальные тесты работы от солнечной панели. |

## 🛠️ Как принять участие?

1. Сделайте **Fork** этого репозитория к себе в профиль.
2. Создайте ветку для своих решений (например, `git checkout -b my-challenge-path`).
3. Каждую неделю выполняйте публикуемые задания, фиксируйте прогресс и делитесь отчетами в соцсетях с хэштегом `#techtober_challenge`.
4. Общайтесь и задавайте вопросы в нашем Telegram-канале!
